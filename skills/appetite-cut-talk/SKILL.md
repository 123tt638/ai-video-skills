# 食欲胶片 Appetite Cut（原创风格）

> 把口播做成一支「会流口水的」食品广告拆解片：暖琥珀光、微距食材、菜单卡一样的标注、每个关键词都配一声「滋—」。画面的主角是食材的质感，人是带你尝的那个人。
> 学习自 lemo-opuscar 的 STYLE.md 写法（本质、材质、色彩、字体、动态、镜头、声音、招牌动作、坑），风格本身是原创的。不模仿任何真实快餐品牌的 logo、字体、配色比例或广告镜头。

全程中文沟通（用户叫我「可乐」）。工序（转写剪气口卡壳、抠像美颜、timeline.json、lemo 页面 render(t)、mix.py、mux）同 skill「wangan-talking-head-edit」。**首次使用先渲染 3 张风格帧给用户确认**，再出整片。

## 1. 本质与不是什么
1. **先饥饿再解释**：每个段落先给一个让人咽口水的微距镜头（1–1.5 s），再讲它是怎么做出来的。
2. **温度可见**：热的东西冒蒸汽、融化的东西在流动、冰的东西有水珠——画面里至少有一种「温度证据」在动。
3. **菜单卡就是信息层**：所有标注都长得像纸质菜单/价签/配料卡，而不是科技界面。
4. **一口的节奏**：全片只有一次「咬下去」的高潮（停半拍 → 入口声 → 满足表情），其余都在为它蓄力。
不是美食 vlog（不拍做饭过程、不手持晃动），不是综艺花字（不用糖果色与粗描边），不是暗色科技（不用冷色网格与 UI）。

## 2. 材质与渲染（1920×1080）
- 底：深焦糖棕 #1A0F0A → 酸橙暗角的径向渐变，带 4% 纸纹贴图（元素只在片内生成，不加全局颗粒；颗粒在 mux 里加 grain=2）。
- 口播人物：房间压暗到 0.35 并打一层琥珀色乘底；人物肤色暖调磨皮，轮廓光用热橙 #FF8A3D。
- 食材素材：统一调色 `contrast 1.1 · saturate 1.12 · 暖高光 + 高光轻微光晕`；微距镜头可高速慢放（帧混合）。
- 粒子：蒸汽（半透明白向上漂、噪声扰动）、火星（橙金小点上升闪烁）、芝麻（落下弹跳），全部由种子随机数按 t 计算。
- 菜单卡：米白卡纸 #F6EBD8、细红双线边、圆角 10、轻微翻角阴影；价签是红底白字三角缺口。

## 3. 色彩
- 焦糖棕（底）、热橙 #FF8A3D（光/温度）、芝士黄 #FFC83D（关键词/重点）、番茄红 #E8432E（价签/印章/错误做法）、生菜绿 #7BC043（对的做法/勾）、奶油白 #F6EBD8（卡纸/文字）。
- 一屏最多两种强调色；绿色只给「正确/完成」。

## 4. 字体与字幕
- 中文标题 Noto Serif CJK SC Black（菜单感），正文与字幕 Noto Sans CJK SC 900；数字价签用 Lilita One。
- 字幕：底部居中，84px 奶油白 + 焦糖色软阴影；关键词变芝士黄并「融化」下坠 6px 再弹回（0.2 s）。一句一行，≥1.8 s。
- 屏幕大字不超过 8 个字。

## 5. 动态
- 入场：菜单卡像被放在桌上——从上方轻落、旋转±3° 停住，带一点过冲；价签从 1.6× 砸到 1×。
- 关键词同步：食材名被说出的那一帧，对应食材微距切入，配料卡打勾。
- 镜头始终有「呼吸」：慢推 1.00→1.04；但不晃动。
- 转场：蒸汽擦除（一团蒸汽遍布画面再散开，0.4 s）或切在「咬/切/倒」动作点上的匹配切；不用白闪。

## 6. 镜头语法
| 镜头 | 表达 | 用于 |
|---|---|---|
| 微距慢推 | 质感、美味 | 食材介绍、钩子 |
| 口播近景 + 右侧菜单卡 | 信任、讲解 | 步骤、方法 |
| 分屏「生活照 vs 广告照」 | 差距 | 讲广告为什么好看 |
| 配料层爆炸图（层层分离再合拢） | 结构 | 汉堡/蛋糕/饮品分层 |
| 冻结咬口 | 高潮 | 全片只一次 |

## 7. 声音
- 配乐：90–100 BPM 暖 funk/lo-fi（电钢琴和弦、圆润贝斯、轻鼓），咬口前一拍全部停。
- 食欲音效：滋滋煲烤（带通噪声脉冲）、纸张摩擦、脆口咀嚼、拉丝、倒饮料气泡、开罐；卡片落桌的轻哒、价签砸下的闷哚。
- 人声高于音乐 10 dB，音效在人声间隙里放大；-14 LUFS。

## 8. 招牌动作（按需取用）
1. **饭前钩子**：开头 1.5 s 三个微距硬切 + 滋滋声 + 一句大字。
2. **配料卡打勾**：说一样食材勾一项，食材小图飞进卡里。
3. **分层爆炸图**：产品各层上下拉开，每层一张小标签，再合拢。
4. **生活照 vs 广告照**：左去饱和、右暖调，中间一枚红印章「差在光」。
5. **冻结咬口**：咬下前停半拍，音乐断，入口声后满足表情 + 大字。
6. **菜单收尾**：全片要点汇成一张菜单，每项一个价签（用「步骤」代替价格），然后完整播放成片。

## 9. 坑
- 粒子和蒸汽必须由 t 重算，否则多 worker 渲染会跳。
- 暖色过头会让人脸发橙：人物单独调、不覆盖琥珀层。
- 菜单卡字多会变成 PPT：一张卡最多 3 行。
- 不冒用真实品牌；案例品牌名只在用户自己的广告里出现。

## 10. 变化空间
可换：品类（热食/冷饮/甜品）、主强调色（冷饮可换冰蓝 #4FC3F7、水珠替代蒸汽）、配乐曲风、时长。不可换：先饥饿再解释、温度证据、菜单卡信息层、全片只一个咬口高潮。
