# 战术板拆解口播（lemo-opuscar · Sports Telestrator）

用户发来一条口播 + 一条要拆解的案例（广告、爆款视频、镜头片段），做成 1920×1080 横屏「解说员拆战术」风格。全程中文沟通，用户叫我「可乐」。运行第三方仓库脚本前先征得用户许可。

通用工序（转写与剪气口卡壳、抠像美颜压暗背景、timeline.json、lemo 页面渲染、mix.py、mux 交付）与 skill「wangan-talking-head-edit」完全相同，先按它搭好环境和素材；本 skill 只规定换成战术板风格后的画面与声音。开工前读 `styles/telestrator/STYLE.md`。

## 风格不变量
- **先看再拆**：任何案例片段先 1× 完整播一遍，再倒带、定格、讲解；解释永远不先于画面。
- **一次定格只说一件事**：一个标签 + 最多两组线。同一段素材反复用，每遍挖深一层。
- **画在真实画面上**：圈圈在主体下方（透视椭圆 ry=0.36r，外圈虚线旋转），箭头顺着真实动作路径。
- **数据从画面里数出来**：秒表按源帧计时（镜头时长、停顿几帧），量不出的不说。
- 配色角色固定：荧光黄 #FFD400 = 我们要看的主体/关键处理；青 #3FD8FF = 对照/另一种做法；红 #FF3B30（半透明填充+虚线边）= 缺失的、被忽略的；粉笔白 #F4F1E8 = 中性标注；板面底 #0C1411。
- 字体：标签 Noto Sans SC 900 40px（黑卡+左侧色条+小字英文），数字 Barlow Condensed 800 Italic（无则用 Lilita One），时码 等宽字体；不用手写体。

## 口播怎么放进来
- 片头与片尾是「演播室」：压暗虚化的房间 + 抠像人物（同 wangan 口播镜头），右上角角标 `拆解室 · ANALYSIS`（黄块 + 模式行 LIVE 红 / ANALYSIS 黄 / REPLAY 青）。
- 拆解段落案例全屏，口播在左下或右下圆窗。
- 左上「源时钟」：`❚❚ 04.20s F106`（慢放 ▶ ½，倒带 ◀◀），只在分析镜头显示。
- 字幕：底部黑条 0.64 透明 + 4px 黄边，中文 38px，一行不换行（太长就拆句）。

## 剪辑语法（每一段案例）
1. 1× 播放（原声）→ 倒带 0.6 s（反放+±13px 抖动+白色磁带条+大 ◀◀ REWIND）
2. 定格①：白闪 0.1 s（0.55）+ 推镜 1.035→1.0（0.35 s）+ 去饱和 42% + 冷色 + 暗角加重，之后 1.2% 慢推。顺序：圈（谁）→ 区域/连线（发生了什么）→ 标签（一句结论），间隔 0.3–0.6 s。定格 1.8–2.4 s。
3. 慢放 0.6–0.85×（相邻帧混合）→ 定格② → 带秒表慢放 → 定格③。一段最多 2–4 次定格。
4. 聚光：焦点椭圆外压暗到 0.42。马克笔线：黑描边+彩色芯+发光+细高光，沿长度画出，最后 10% 弹出箭头；虚线=应该这样/下一步，实线=已发生。
5. 双机位对比：两个 960×1080 窗口 + 6px 黄分割线，各自播到同一拍一起定格（适合「改前 vs 改后」「别人 vs 我们」）。
6. 总结板：压平成一张数据卡（左标签右大黄数字，关键项红圈），全片只用一次。可用分镜表或剪辑轨道做这张板。
- 段落之间只用黄色斜带擦除（0.34 s，深色边）；段内硬切；不用溶解翻页。
- 比较帧（数据卡、对比板）画完后至少停 2.5 s。

## 声音
- 120 BPM 乐队感配乐（鼓、电贝斯、短促铜管、定音鼓、钟琴）。**定格时鼓停**：一声铜管 stab + 定音鼓 + 低频 thump + 快门声，然后只留闭镲；播放恢复时音乐重新起。
- 拟音：马克笔吱吱声（2–5 kHz 带通噪声+颤动）、圈圈弹出 pop、标签落地 tick、擦除 whoosh、倒带磁带电机声、秒表每 0.2 s 一哒。
- 案例原声在 1× 播放时全音量，定格下只留低通底床；人声把其他声音压到 0.55。-14 LUFS。

## 结尾
口播讲完接「完整片段 REPLAY」：角标切 REPLAY 青色，案例成片 1× 完整播放，不加任何标注。
