# 货架爆品 Shelf Pop（原创风格）

> 把口播做成一次「逛便利店」：产品在货架上亮相，卖点是一张张促销价签，对比是两个货位，结论是一张打印出来的小票。明亮、轻快、有购物的爆点。
> 学习自 lemo-opuscar 的风格写法；风格原创。不使用任何真实连锁便利店的招牌、制服配色、字体或商标；货架上的其他商品一律是无品牌的纯色示意包装。

全程中文沟通（用户叫我「可乐」）。工序同 skill「wangan-talking-head-edit」。首次使用先渲染 3 张风格帧给用户确认。适合用户的快消类 AI 广告账号。

## 1. 本质与不是什么
1. **产品在货架上被选中**：一排灰扑扑的示意包装里，主角产品亮起、弹出、转身——「从一堆里被看见」是全片核心意象。
2. **一个卖点 = 一张价签**：所有关键信息做成促销价签/爆炸贴，砸在产品旁；一张签不超过 6 个字 + 一个数字或符号。
3. **扫码即揭示**：分析或拆解时用「条形码扫描」——红色扫描线扫过，哔一声，弹出信息。
4. **小票即总结**：要点汇总是一张从下往上打印出来的热敏小票，逐行出现，最后一行是结论。
不是电商直播（不喊价、不倒计时逼单），不是食欲胶片（不走暖暗电影感，而是明亮门店感）。

## 2. 材质（1920×1080）
- 场景：纯色钣金货架（三层、白色架板 + 灰色价签槽）、冷白日光灯顶光（上方长条光带）、地面细反射。全部用代码画成扁平+轻微阴影的 2.5D。
- 示意包装：罐、盒、袋三种几何体，低饱和单色 + 一条白色腰封，没有文字和图案。
- 主角产品：用户的产品图或成片帧（抠图或卡片），高饱和，边缘有一圈白色展示光。
- 口播人物：可站在货架前（抠像 + 货架虚化做背景），或使用原房间压暗虚化；人像美颜同 wangan。
- 价签：爆炸星形（黄底红字）、长条价签（白底红字 + 黑色条码）、圆形「新品」贴（绿底白字）；边缘有轻微卷曲阴影。

## 3. 色彩
- 门店白 #F7F7F4、货架铁灰 #C9CDD2、促销黄 #FFE14D、促销红 #E8312A、新品绿 #19B36B、扫码红线 #FF2D2D、小票纸 #FBFAF5 + 热敏灰字 #3A3A3A。
- 主角产品是画面里最饱和的东西；促销黄/红只用在价签上。

## 4. 字体与字幕
- 价签大字 Noto Sans CJK SC Black，数字 Lilita One（带斜切）；小票用等宽字体（热敏打印感，字距稍宽）。
- 字幕：底部居中白色长条「价签条」（白底 + 左端红色小方块 + 黑字 56px），关键词促销红；一句一行。

## 5. 动态
- 价签砸贴：从 1.8× 砸到 1×（0.14 s），贴上后边角微微翘起再压平。
- 产品「被拿起」：从货架向前弹出，放大、轻旋转成 3/4 角，地面阴影收缩。
- 扫码：红线从上到下扫 0.35 s，扫完一道绿闪 + 「哔」，信息卡从扫描处展开。
- 小票：从画面下方「打印」上升，每行一声，踩着节拍；最后一行加粗 + 虚线撕口。
- 转场：货架横移（镜头沿货架快速平移到下一个货位，0.4 s，带运动模糊）；或推车横穿画面擦除。

## 6. 镜头语法
| 镜头 | 表达 | 用于 |
|---|---|---|
| 货架全景，主角亮起 | 从一堆里被看见 | 开场、点题 |
| 产品特写 + 三张价签 | 卖点 | 卖点、策略拆解 |
| 左右两个货位 | 对比 | 改前改后、竞品示意 |
| 扫码特写 | 揭秘 | 配方、数据、广告的小心机 |
| 口播 + 货架背景 | 店员在推荐 | 讲解、过渡 |
| 小票打印 | 结账 | 总结 |

## 7. 声音
- 配乐：110–120 BPM 明亮流行（拨弦吉他、响指、木琴、轻快鼓），商场背景音乐感但更有力。
- 音效：扫码「哔」、收银台「叮」、小票打印机滋滋声、价签贴纸「啪」、货架拿起的塑料/纸盒声、自动门「欢迎光临」式的两音铃（自己合成，不录真实店铺提示音）。
- 人声高于音乐 10 dB，-14 LUFS。

## 8. 招牌动作
1. **进店开场**：两音门铃 + 货架全景推进，主角产品亮起弹出。
2. **三张价签**：讲一个卖点砸一张，最后一张是爆炸星。
3. **扫码拆解**：扫产品/广告帧 → 弹出「广告用了什么招」信息卡。
4. **货位对比**：左货位普通拍法（去饱和、标签「普通」），右货位 AI 广告拍法（亮、标签「爆品」）。
5. **小票结账**：全片步骤打印成小票，合计一行是一句结论。
6. **上架展示**：口播结束后，产品放回货架正中，镜头推入包装→完整播放广告成片。

## 9. 坑
- 货架上不能出现任何真实品牌；示意包装保持无字无图。
- 价签上的数字必须是口播里真实说的（步骤数、时长、镜头数）；用户没说价格就不写价格。
- 价签太多会吵：同屏最多 3 张，新的贴上时最旧的退场。
- 冷白门店光会让人脸发青：人物单独保留暖肤色。

## 10. 变化空间
可换：场景（超市、自动售货机、冰柜、咖啡吧台）、促销色、配乐风格。不可换：从一堆里被看见、一卖点一价签、扫码即揭示、小票即总结。
