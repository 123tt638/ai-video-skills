# 导演场记本 Director's Slate（原创风格）

> 把口播做成一本「翻开的导演工作本」：场记板一拍就换场，每个镜头是一张带编号的镜头卡，铅笔线稿变成 AI 生成的成品，取景器里浮着焦段、光圈、色温。观众感觉自己坐在监视器后面。
> 学习自 lemo-opuscar 的风格写法；风格原创，不复制任何片场、器材品牌的 logo 或界面。

全程中文沟通（用户叫我「可乐」）。工序同 skill「wangan-talking-head-edit」。首次使用先渲染 3 张风格帧给用户确认。特别适合用户的「AI 广告/MV 导演」内容（分镜、提示词、运镜、景别）。

## 1. 本质与不是什么
1. **从纸到画面**：每个概念先以铅笔线稿/文字卡出现，再「显影」成真实画面（成片帧）。观众看到的是创作过程，不只是结果。
2. **镜头即单位**：信息以「镜头卡」组织——编号、景别、运镜、时长、一句描述。
3. **参数诚实**：焦段、光圈、色温、快门是说明拍法的，写的是提示词里的设定，标「提示词设定」，不冒充实拍数据。
4. **场记板定节奏**：每个章节一拍场记板（场次/镜次/条次 = 章节/步骤/版本），那一下是全片重拍。
不是综艺（不用糖果色、不跳不弹），不是新闻（没有标题条），不是科技发布（不用 UI 窗口）。

## 2. 材质（1920×1080）
- 工作台：深灰绿桌面 #1E2420，上面是奶白分镜纸 #EEE8DA（淡蓝细横线、左侧穿孔）、纸胶带、回形针。轻微纸张阴影和 ±1° 倾斜。
- 铅笔线稿：从成片帧用边缘检测生成灰黑铅笔线（预处理导出 PNG），外加手绘箭头表示运镜方向（推/拉/摇/移/环绕）。
- 「显影」：线稿上用一道斜向光带扫过，扫过处变成彩色成片帧（0.5 s）。
- 取景器层：白色细角标、中心十字、三分线（可开关）、右下参数行「35mm · f/2.0 · 3200K · 推」。
- 口播人物：压暗虚化房间 + 抠像；人物画面也套取景器层，左上角红点 REC 与「导演解说」。

## 3. 色彩
- 桌面深绿灰、分镜纸奶白、铅笔灰 #4A4A48、场记板黑白条、**场记红 #E5392E**（标注圈、印章、REC）、**胶片黄 #F2B705**（关键词、当前镜头）。成片帧保持自身色彩，是画面中最饱和的部分。

## 4. 字体与字幕
- 镜头卡与标题：Noto Sans CJK SC 900；参数与编号用等宽字体（无则用 Noto Sans Mono）；铅笔批注用手写感字体（仅限纸上批注，如 ZCOOL KuaiLe，注意字库只含常用字）。
- 字幕：底部左对齐的「场记条」——黑底白字 54px，左侧一个黄色镜次号（如 S02），关键词胶片黄。

## 5. 动态与转场
- **场记板转场**：场记板从下方入画，写着「场次/镜次/条次」→ 拍板合上（重拍）→ 向上抽离，露出下一场；整个过程 0.7 s。全片只在章节切换用。
- 章节内：硬切；镜头卡像被手放在桌上——滑入+轻旋转停住；批注用「写出来」的描边动画。
- 运镜演示：讲到「推/拉/摇/移/环绕」时，在成片帧上真的做这个运镜，叠一个取景框轨迹。

## 6. 镜头语法
| 镜头 | 表达 | 用于 |
|---|---|---|
| 俯拍工作台，镜头卡铺开 | 全局规划 | 分镜表、结构 |
| 推进一张卡 → 线稿显影成画 | 从想法到成片 | 每一个镜头讲解 |
| 分屏：提示词文字 vs 生成结果 | 因果 | 提示词教学 |
| 两条 take 并排（Take 1 红叉 / Take 2 红圈） | 取舍 | 改版、抽卡、反馈 |
| 口播近景 + 取景器层 | 导演在讲戏 | 观点、过渡 |

## 7. 声音
- 配乐：电影感的极简弦乐铺底与钢琴单音（采样器的弦乐/钢琴，或合成替代），章节重拍在场记板合上那一帧。
- 音效：场记板「啪」、铅笔沙沙声（写批注时）、纸张拖动、快门、胶片过片声（显影时）、摄影机马达低鸣（REC）。
- 人声高于音乐 10 dB，-14 LUFS。

## 8. 招牌动作
1. **拍板开场**：黑场中场记板写着题目拍下，切入成片最强的一帧。
2. **线稿显影**：铅笔分镜 → 光带扫过 → AI 成品。
3. **镜头卡墙**：9 张卡俯拍铺满桌面，讲到哪张哪张被红圈圈起。
4. **提示词拆句**：提示词长句被划分为【主体】【光影】【运镜】【风格】彩色下划线，每段对应画面变化。
5. **Take 对比**：失败版和成功版并排，红印章「OK TAKE」。
6. **杀青**：片尾场记板写「杀青」，然后完整放映成片（画幅保持原比例，如 21:9 加黑边）。

## 9. 坑
- 手写字库只含少量字，批注前检查每个字是否可显示，缺字就换 Noto Sans。
- 线稿预处理要去掉成片里的品牌字，以免线稿乱。
- 参数行只写提示词里真实写过的设定；没写就不显示。
- 场记板不要每句都拍，只在章节切换。

## 10. 变化空间
可换：桌面材质（木桌/灰度卡/黑板）、场记板样式、配乐情绪、章节数。不可换：从纸到画面、镜头卡为单位、参数诚实、场记板定章节。
