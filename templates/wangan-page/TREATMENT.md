# <片名> · 横屏网感口播（TREATMENT 模板）

风格：字幕新闻 Caption News（主骨架：全屏画面、超大分块字幕、关键词黄底、硬切、角标与来源标签）
＋ 综艺节奏扁平 Game Show Flat（回合卡、糖果色条纹布景、硬投影贴纸、判定词、节拍推镜）。
素材：口播（已剪气口卡壳，约 xx s）、要拆解的广告成片（约 xx s）、由成片整理的 9 镜分镜表。

## 三种结构（每片都要重新写，然后选一个）

A. 时间顺序：开场 → 方法步骤 → 结尾 → 成片。稳，但第一秒没有钩子。
B. 结果先行：第一秒闪成片最好看的镜头和一句大字，再进口播；每个步骤一张回合卡，每回合以一个判定词收尾；口播结束接完整成片。
C. 拆解倒叙：先放完整成片，再逐镜倒推做法。成片放在前面会让口播显得长。

选择：B（钩子在前、回合制让步骤一眼可分、成片作为终局奖励）。

## 结构（按口播时间填写）

| 段 | 内容 | 画面 |
|---|---|---|
| 钩子 0–1.6 s | 成片最强的几个镜头硬切 + 大字 | 全屏成片 + 贴纸 |
| 开场 | 打招呼 / 点题 | 口播全屏（暗房虚化 + 人物提亮），角标 |
| ROUND 1 | 第一步 | 回合卡 → 人物右移，关键词贴纸逐个落下 |
| 微观与镜头 | 讲镜头/画面的段落 | 成片微距全屏快切，REC 取景框，判定词 |
| ROUND 2 | 分镜 / 提示词 | 分镜表全屏，荧光笔扫过对应分镜，推近逐镜 |
| ROUND 3 | 生成 | 步骤贴纸卡依次弹出 |
| ROUND 4 | 剪辑 | 剪辑轨道版图，播放头扫过，判定词砸下 |
| FINAL | 品牌落版 | 成片落版全屏 |
| 结尾 | 收束一句 | 口播推近 + 贴纸 |
| 成片展示 | 完整广告 | 回合卡「成片展示」→ 原画幅全片 |

声音：口播原声（降噪、压缩、提亮）；120 BPM 原创节奏配乐，人声处自动避让；硬切、贴纸、判定词、打字、播放头都配程序生成音效。
